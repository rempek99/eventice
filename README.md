# Eventice

- Created for fun and self development
- Started 31.03.2025
- Cheers

## Stack

- 🗃️ DB: PostgreSQL
- 🛠️ BackEnd: String Boot
- 💻 FrontEnd: AngularJS

## Main Project Mile Stones

- Application backend is implemented using Spring Boot ✅
- Application backend is separated to modules (microservices), Users service, Events service, Data service (photos, attachments). Communication between services is handled by message broker (rabbitmq?)
- Main Features:

  - Creating Events
  - Adding users to events as participants
  - Editing event properties (granting co-creator role, enabling/desabling creator confirmation before posting new content in event feed, changing visibility of event (private / visible for contacts / public))
  - Adding users to Contacts
  - Presenting feed (events created / participied by contacts, current events updates)
  - Event group chatting
  - Event gallery
  - Event costs (adding puchaces and sharing costs by participants)
  - Event files (pdf etc.)
  - Event notifications (User can push notification to all event participations to warn about some important issue)
  - Events callendar
  - Events Map

- Web Application (webpage) implemented using Angular
- Mobile Application (framework not defined)
