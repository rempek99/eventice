# HTML

## 🧱 Essential HTML Elements Cheat Sheet

### 🏗️ Structure Elements

| Element    | Description                                                           |
| ---------- | --------------------------------------------------------------------- |
| \<html>    | The root element that wraps the entire HTML document.                 |
| \<head>    | Contains metadata, links, title, and scripts.                         |
| \<body>    | Holds all visible page content.                                       |
| \<div>     | A generic container used for grouping content or layout purposes.     |
| \<span>    | An inline container for styling or grouping small text segments.      |
| \<section> | Defines a thematic grouping of content (like a chapter or topic).     |
| \<article> | Represents a self-contained piece of content (e.g., blog post, news). |
| \<header>  | Defines the introductory section (often includes logo, nav, title).   |
| \<footer>  | Represents the footer for a page or section.                          |
| \<main>    | Marks the main content of the document (unique per page).             |
| \<nav>     | Defines navigation links (menus, table of contents, etc.).            |

### ✍️ Text & Content Elements

| Element       | Description                                     |
| ------------- | ----------------------------------------------- |
| \<p>          | Paragraph of text.                              |
| \<h1> – \<h6> | Headings; \<h1> is most important, \<h6> least. |
| \<a>          | Hyperlink to another page or location.          |
| \<ul>         | Unordered (bulleted) list.                      |
| \<ol>         | Ordered (numbered) list.                        |
| \<li>         | List item (used inside \<ul> or \<ol>).         |
| \<img>        | Displays an image.                              |
| \<strong>     | Indicates strong importance; usually bold.      |
| \<em>         | Emphasizes text; usually italic.                |
| \<br>         | Inserts a line break.                           |

### 🧾 Form Elements

| Element     | Description                                                  |
| ----------- | ------------------------------------------------------------ |
| \<form>     | Container for user input controls.                           |
| \<input>    | Field for user data (text, email, password, etc.).           |
| \<button>   | Clickable button for submitting forms or triggering actions. |
| \<label>    | Describes an input field (improves accessibility).           |
| \<textarea> | Multi-line text input box.                                   |
| \<select>   | Drop-down list control.                                      |
| \<option>   | Defines an item inside a \<select> list.                     |

### 🎞️ Media Elements

| Element   | Description                                        |
| --------- | -------------------------------------------------- |
| \<video>  | Embeds a video file.                               |
| \<audio>  | Embeds an audio file.                              |
| \<source> | Specifies a media source for \<video> or \<audio>. |

### 🧩 Metadata & Linking Elements

| Element   | Description                                                       |
| --------- | ----------------------------------------------------------------- |
| \<title>  | Sets the page’s title (shown in browser tab).                     |
| \<meta>   | Defines metadata like description, charset, or viewport settings. |
| \<link>   | Connects external resources (like CSS files or icons).            |
| \<script> | Embeds or references JavaScript code.                             |
| \<style>  | Embeds CSS directly within the HTML document.                     |
