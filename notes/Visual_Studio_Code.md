# Visual Studio Code

## Shortcuts

### 🗂️ File & Project Management

| Shortcut     | Action                           |
| ------------ | -------------------------------- |
| ⌘ + N        | New file                         |
| ⌘ + O        | Open file                        |
| ⌘ + ⇧ + N    | New window                       |
| ⌘ + W        | Close current editor tab         |
| ⌘ + ⇧ + T    | Reopen last closed tab           |
| ⌘ + S        | Save current file                |
| ⌘ + ⇧ + S    | Save As…                         |
| ⌘ + K, ⌘ + S | Open Keyboard Shortcuts settings |
| ⌘ + ,        | Open Settings panel              |

### 🔍 Search & Navigation

| Shortcut  | Action                               |
| --------- | ------------------------------------ |
| ⌘ + P     | Quick open file by name              |
| ⌘ + ⇧ + O | Go to symbol in file                 |
| ⌘ + T     | Go to symbol in workspace            |
| ⌘ + ⇧ + M | Open Problems panel (linting/errors) |
| ⌘ + F     | Find in current file                 |
| ⌘ + ⇧ + F | Search across files                  |
| ⌥ + ↑ / ↓ | Move line up or down                 |
| ⌃ + G     | Go to line number                    |
| ⌘ + ← / → | Jump to start/end of line            |

### ✍️ Editing & Selection

| Shortcut      | Action                                     |
| ------------- | ------------------------------------------ |
| ⌘ + D         | Select next occurrence of highlighted word |
| ⌘ + ⇧ + L     | Select all occurrences of highlighted word |
| ⌥ + Click     | Add multiple cursors                       |
| ⌥ + ⇧ + ↑ / ↓ | Copy line up/down                          |
| ⌘ + /         | Toggle line comment                        |
| ⌥ + ⇧ + A     | Toggle block comment                       |
| ⌘ + K, ⌘ + U  | Uppercase selected text                    |
| ⌘ + K, ⌘ + L  | Lowercase selected text                    |
| ⌃ + Space     | Trigger IntelliSense (autocomplete)        |

### 🧭 View & Layout

| Shortcut      | Action                        |
| ------------- | ----------------------------- |
| ⌘ + B         | Toggle sidebar visibility     |
| ⌘ + J         | Toggle terminal panel         |
| _⌘ + _        | Split editor                  |
| ⌘ + 1 / 2 / 3 | Focus editor group 1, 2, or 3 |
| ⌘ + ⇧ + E     | Open Explorer                 |
| ⌘ + ⇧ + F     | Open Search view              |
| ⌘ + ⇧ + D     | Open Run & Debug view         |
| ⌘ + ⇧ + X     | Open Extensions view          |

### 🧠 Code Navigation & Refactoring

| Shortcut     | Action                         |
| ------------ | ------------------------------ |
| F12          | Go to definition               |
| ⌥ + F12      | Peek definition                |
| ⌘ + ⇧ + F10  | Show references                |
| ⌘ + K, ⌘ + F | Format selected code           |
| ⌥ + ⇧ + F    | Format entire document         |
| F2           | Rename symbol                  |
| ⌘ + .        | Quick fix (suggested refactor) |

### 🧰 Terminal & Git

| Shortcut                | Action                         |
| ----------------------- | ------------------------------ |
| ⌃ + `                   | Toggle integrated terminal     |
| ⌘ + ⇧ + C               | Open new terminal window       |
| ⌘ + Enter (in terminal) | Run selected line              |
| ⌘ + ⇧ + G               | Open Source Control (Git) view |
| ⌘ + K, ⌘ + G            | Stage selected changes         |
| ⌘ + K, ⌘ + U            | Unstage selected changes       |
